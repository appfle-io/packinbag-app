# 팩인백 기능명세서 (docs/spec)

이 폴더는 **지금 앱이 어떻게 동작하는지**만 적는다. 언제 무엇이 바뀌었는지는 `docs/packinbag_settings_spec_v1.md`(변경 이력)에, 손으로 확인할 항목은 `docs/qa_checklist.md`에 둔다.

- 소스를 읽고 쓴다(기획 문서가 아니라 코드가 기준). 코드와 명세가 다르면 코드가 맞고, 명세를 고친다
- 의도인지 버그인지 모르는 것은 추측해서 적지 않고 각 파일 맨 아래 **확인 필요**에 모은다
- 기능을 추가·수정할 때: 이 폴더의 해당 파일을 먼저 읽기 → 바뀐 규칙을 명세에 반영 → 테스트 추가·수정 → 구현 → 변경 이력(settings_spec) · QA 체크리스트 갱신

## ID 규칙

- `영역-묶음-번호`. 예: `BAG-PSHEET-03` = 가방 화면 › 팩 시트 › 3번 규칙
- 번호는 지우지 않는다. 기능이 빠지면 줄을 남기고 "삭제(날짜)"로 표시 → 테스트 · QA에서 같은 ID를 찾을 수 있게
- 테스트 이름 앞에 ID를 붙인다: `it("BAG-CHK-04 마지막 체크로 다 싸면 lastPackedAt 기록", …)` → `npm test -- -t BAG-CHK`로 그 묶음만 실행
- QA 체크리스트 항목에도 ID를 적는다

## 항목 쓰는 틀

```
### 묶음-ID 이름
- 진입: 어디서 어떻게 여는지
- 코드: 파일 경로(호출하는 쪽)
- 닫기: 닫는 방법

| ID | 요소 | 보이는 조건 | 동작 · 문구 |
|---|---|---|---|

- 데이터: 바뀌는 필드 · 저장 경로
- 제한 · 예외: 개수 제한, 오프라인, 읽기 전용, 잠금
- 테스트: 단위 / 규칙 / QA
```

## 공통 표기

- "시트" = 아래에서 올라오는 창. 1024px 이상에서는 화면 가운데 창(바깥 · Esc · X로 닫기, 끌어내리기 없음)
- "길게 누르기" = 터치 450ms, 8px 넘게 움직이면 취소. PC 마우스는 오른쪽 클릭(`components/v2/ui/useLongPress.ts`). 길게 누른 직후의 클릭은 무시(체크가 같이 토글되지 않음)
- "토스트" = 화면 아래 한 줄 알림. "되돌리기"가 붙은 것은 그 안에서 되돌릴 수 있음
- "프리미엄 시트" = `PremiumSheet`. 지금은 `lib/freeLaunch.ts` `FREE_LAUNCH = true`라 **모든 사용자가 프리미엄**이다. 명세의 무료/프리미엄 구분은 FREE_LAUNCH를 끈 뒤 기준
- "guard" = 읽기 전용(무료 한도 초과로 잠긴) 가방이면 동작 대신 이용권 안내를 띄우고 멈춘다(`useBagDocument.guard`)
