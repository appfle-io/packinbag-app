## 1. BAG-SCR 화면 구조 (위에서 아래로)

| ID | 요소 | 보이는 조건 | 동작 · 문구 |
|---|---|---|---|
| BAG-SCR-01 | 뒤로(‹) | 항상 | 여러 개 선택 중이면 선택만 끝냄. 아니면 가방 목록으로(`onBack(현재 가방)`) |
| BAG-SCR-02 | 접속자 아바타 | 함께 쓰는 가방에서 지금 보는 다른 사람이 있을 때 | 최대 3명 겹쳐 표시, 초록 점. 라벨 "지금 보는 사람 N명" |
| BAG-SCR-03 | 해 아이콘(화면 켜두기) | 화면 켜두기가 켜져 있을 때 | 실제로 켜짐을 잡고 있으면 브랜드색 · 굵게, 못 잡았으면 흐리게. 누르면 바로 끔(토스트 "화면 켜두기를 껐어요") |
| BAG-SCR-04 | 1열/2열 버튼 | 가방 화면 폭이 좁을 때만(@2xl 미만) | `UserProfile.bagPhoneColumns` 1↔2 전환(계정 저장, 실패는 무시). 넓은 화면은 폭에 따라 자동 |
| BAG-SCR-05 | 사람 아이콘 | 항상 | 멤버 시트(§ BAG-MEM) |
| BAG-SCR-06 | ⋯ | 항상 | 더보기 시트(§ BAG-MORE) |
| BAG-SCR-07 | 읽기 전용 줄 | 잠긴 가방(readOnly) | 눈 아이콘 + "무료 한도를 넘어 읽기 전용이에요. 보기만 할 수 있어요." + "풀기" → 이용권 안내(`onRequestUnlock`) |
| BAG-SCR-08 | 가방 이름 칸 | 항상 | 큰 제목. 새 가방이면 자동 포커스. 엔터 = 확정(blur). 앞뒤 공백 제거, 빈 값 · 같은 값이면 저장 안 함. 읽기 전용이면 고칠 수 없음 |
| BAG-SCR-09 | 메타 줄 | 아래 중 하나라도 있을 때 | "D-3 · 10월 12일 · 마지막으로 다 싼 날 · 어제 오후 6:20 · 3명"을 " · "로 이음. 출발일 없으면 날짜 부분 빠짐, 멤버 1명이면 인원 빠짐 |
| BAG-SCR-10 | 설명 한 줄 | `notice`가 있을 때 | 최대 2줄까지 보이고 넘치면 자름 |
| BAG-SCR-11 | 첨부 줄 | `images`가 있을 때 | 72px 정사각형, 가로 스크롤. 사진은 썸네일, 그 밖은 확장자 글자(PDF 등). 누르면: 사진 → 사진 보기, PDF → PDF 보기, 그 밖 → 바로 저장(실패 토스트 "파일을 저장하지 못했어요"). 오른쪽 위 ✕ = 지우기(§ BAG-ATT-09) |
| BAG-SCR-12 | 진행 줄 | 체크 아이템이 1개 이상 | "챙긴 수 / 전체" + 상태 배지 + "다시 싸기" + 진행 막대(§ BAG-CHK) |
| BAG-SCR-13 | 필터 칩 줄 | 체크 팩(메모 제외)이 1개 이상 | 스크롤해도 위에 붙음(sticky). § BAG-FLT |
| BAG-SCR-14 | 팩 목록 | | 미분류(아이템이 있을 때만) → 나머지 팩(저장 순서). 폴더 타입 팩은 그리지 않음. 무료 화면에서는 날씨 추천 팩 숨김(`getViewablePacks`) |
| BAG-SCR-15 | 빈 가방 | 그릴 팩이 하나도 없을 때 | "아직 비어 있어요" / "보관함의 팩을 불러오거나, 아래에 바로 적어 보세요." + "팩 불러오기" 버튼 |
| BAG-SCR-16 | 필터 결과 없음 | 팩은 있는데 필터로 다 걸러짐 | "남은 것" 필터면 "다 챙겼어요", 그 밖 "보여줄 항목이 없어요" |
| BAG-SCR-17 | 하단 줄 | 항상 | 여러 개 선택 중이면 선택 줄(§ BAG-MULTI), 아니면 입력창(§ BAG-ADD) |
| BAG-SCR-18 | 열 수 | | 가방 화면 폭 기준: 672px 미만 1열(2열 설정이면 2열, 촘촘하게) · 672px 이상 2열 · 896px 이상 3열. 글 아이템은 한 줄 전체 |

## 2. BAG-CHK 체크 · 다시 싸기 · 상태

- 코드: `hooks/bag/useBagItems.ts`(toggleItem · uncheckAll · setPackChecked), `hooks/bag/bagStats.ts`

| ID | 규칙 |
|---|---|
| BAG-CHK-01 | 체크 아이템을 누르면 체크 ↔ 해제. 햅틱(가벼운 탭). 글 아이템은 누르면 아이템 시트(체크 없음). 글 아이템은 아이템 시트의 "종류"로 만든다(BAG-ISHEET-11) |
| BAG-CHK-02 | 진행률 · 상태 계산은 **체크 팩의 체크 아이템만** 센다(메모 · 폴더 · 글 아이템 제외). 화면에 보이는 팩 기준(무료 화면의 날씨 추천 팩 제외) |
| BAG-CHK-03 | 상태: 체크 0개이거나 아이템 없음 = "비어 있음"(회색) / 일부 = "싸는 중"(브랜드) / 전부 = "다 쌌어요"(진한 배지) |
| BAG-CHK-04 | 체크 상태가 바뀌는 모든 변경에 `lastCheckedAt = 지금`. 그 변경으로 "전부 체크"가 되면 `lastPackedAt = 지금`, `lastPackedBy = 나` |
| BAG-CHK-05 | 다 싼 순간(이전 상태가 "다 쌌어요"가 아니었는데 됨) 성공 햅틱 한 번. 이미 다 싼 가방을 열 때는 울리지 않음 |
| BAG-CHK-06 | "다시 싸기": 챙긴 게 0개이거나 읽기 전용이면 비활성. 누르면 메모 제외 모든 체크 아이템 해제, `lastCheckedAt` 갱신, **`lastPackedAt`은 그대로**. 토스트 "모두 해제했어요. 새로 싸 볼까요?" + 되돌리기(직전에 체크돼 있던 것만 다시 체크) |
| BAG-CHK-07 | 팩 시트 "모두 체크/모두 해제": 그 팩의 체크 아이템 전부. BAG-CHK-04 도장 규칙 같이 적용 |
| BAG-CHK-08 | 팩 머리줄 오른쪽: 체크 아이템이 있으면 "챙긴 수 / 체크 수", 없으면 아이템 수. 전부 챙기면 이름 옆 ✓ |

## 3. BAG-FLT 필터 칩 · 접기 · 보이는 순서

| ID | 요소 | 보이는 조건 | 동작 |
|---|---|---|---|
| BAG-FLT-01 | 전체 (N) | 항상 | N = 전체 체크 수. 모든 팩 |
| BAG-FLT-02 | 남은 것 (N) | 항상 | N = 안 챙긴 수. 안 챙긴 체크 아이템이 있는 체크 팩만, 그 안에서도 안 챙긴 것만. 메모 숨김 |
| BAG-FLT-03 | 내 담당 (N) | 함께 쓰는 가방 + 나에게 맡긴 체크 아이템이 1개 이상 | N = 내 담당 중 안 챙긴 수. 내 담당 아이템이 있는 팩만, 그 안에서도 내 담당만(챙긴 것 포함). 다시 누르면 전체 |
| BAG-FLT-04 | 팩 이름 칩 (N) | 체크 팩마다(미분류 포함) | N = 그 팩의 안 챙긴 수. 그 팩만. 다시 누르면 전체. 고르면 **입력창 넣을 곳도 그 팩으로**(미분류 칩이면 미분류) |
| BAG-FLT-05 | 필터가 사라짐 | 고른 팩이 지워졌거나 내 담당이 없어짐 | 자동으로 전체 |
| BAG-FLT-06 | 자동 접기 | 전체 필터일 때만 | 체크 아이템이 있고 전부 챙긴 팩은 접힌 채로 시작. 그 밖은 펼침 |
| BAG-FLT-07 | 직접 접기 | 팩 머리줄 누르기 | 펼침 ↔ 접힘(200ms). 이 화면을 연 동안만 기억 |
| BAG-FLT-08 | 필터 중 접기 | 전체가 아닌 필터 | 모든 팩 펼침(접기 무시) |
| BAG-FLT-09 | 다 챙긴 아이템 아래로 | 설정 > 가방(`moveCompletedToBottom`, 없으면 켬) | 팩 안에서 챙긴 체크 아이템을 아래로. **화면 순서만**, 저장 순서는 그대로(`lib/itemDisplayOrder.ts`) |
| BAG-FLT-10 | 빈 팩 표시 | 필터 뒤 보여줄 아이템 0개 | 팩 안에 "남은 아이템이 없어요" |

## 4. BAG-ADD 하단 입력창 · 넣을 곳

| ID | 요소 | 보이는 조건 | 동작 · 문구 |
|---|---|---|---|
| BAG-ADD-01 | 팩 불러오기 버튼(왼쪽) | 항상 | 팩 불러오기 시트(§ BAG-IMP). 읽기 전용이면 이용권 안내 |

| BAG-ADD-03 | 입력칸 | 항상 | 자리글 "아이템 추가", 키보드 버튼 "보내기". 읽기 전용이면 비활성. 둥근 칸의 빈 곳을 눌러도 입력칸에 포커스 |
| BAG-ADD-04 | 추가(↑) | 항상 | 글이 없거나 읽기 전용이면 비활성(회색) |
| BAG-ADD-05 | 미분류로 넣기 | 넣을 곳 = 미분류 | 미분류 팩 끝에 체크 아이템 추가. 미분류 팩이 없으면 **맨 위에** "미분류"(isInbox) 팩을 만들어 넣음. 팩이 이미 한도(BAG-LIM-01)면 한도 문구로 막고 글은 남김. 성공하면 칸 비우기 · 필터 전체 · 미분류 펼침 |
| BAG-ADD-06 | 팩에 바로 넣기 | 넣을 곳 = 팩 | 그 팩 끝에 체크 아이템. 칸 비우기, 그 팩 펼침, 다른 팩 필터 중이면 전체로. 60ms 뒤 방금 넣은 줄이 보이게 스크롤 |
| BAG-ADD-07 | 연속 입력 | | 넣을 곳은 바꿀 때까지 유지. 고른 팩이 사라지면(다른 멤버 삭제 등) 미분류로 |
| BAG-ADD-08 | 팩 머리 + | 체크 팩(미분류 제외), 읽기 전용 · 여러 개 선택 중 아님 | 넣을 곳을 그 팩으로 + 팩 펼침 + 입력칸 포커스(iOS 키보드 올라옴). 지금 넣을 곳인 팩의 +는 브랜드색 · 굵게 |
| BAG-ADD-09 | "어디에 넣을까요?" 시트 | 넣을 곳 칩 | 첫 줄 "미분류 · 나중에 팩으로 나눠 담아요", 그 아래 체크 팩(미분류 제외) "이름 · N개". 지금 것에 ✓ · 굵게. 고르면 닫힘 + 그 팩 펼침. 아래 안내 "팩 이름 줄의 +를 누르거나 위쪽 칩에서 팩을 고르면 그 팩으로 바뀌어요." |
| BAG-ADD-10 | 공백 | | 앞뒤 공백 제거, 빈 글은 무시. 중복 이름도 그대로 추가(검사 없음 — **의도**, 연속 입력을 막지 않으려고. AI 가져오기 · 날씨 추천만 중복을 뺀다, 10/17 확인) |

## 5. BAG-PACK 팩 섹션 (체크 팩 · 미분류 · 잠긴 팩)

| ID | 요소 | 동작 |
|---|---|---|
| BAG-PACK-01 | 머리줄 누르기 | 접기/펼치기 |

| BAG-SAVE-02 | 새 가방의 첫 변경은 바로 저장하고 AppShell에 "확정"을 알림(그 전까지는 손대지 않은 새 가방) |
| BAG-SAVE-03 | 화면을 나가거나 · 앱이 뒤로 가거나(visibility hidden) · pagehide · beforeunload면 대기 중 저장을 바로 내보냄(이때 실패 토스트는 안 띄움) |
| BAG-SAVE-04 | 실패 토스트 "실시간 저장에 실패했어요 (오류 코드)" |
| BAG-SAVE-05 | 다른 멤버 · 기기 변경은 AppShell이 이미 구독 중인 가방 목록에서 받음(추가 읽기 없음). 내 변경이 없으면 그대로 반영, 저장 대기 중이면 아이템 단위로 합침. 내 저장이 되돌아온 것(내용 같음)은 다시 그리지도 저장하지도 않음 |
| BAG-SAVE-06 | 저장하는 동안 새 변경이 생기면 "변경 있음"을 유지(빠른 연속 체크가 풀리던 문제 방지, 10/11) |
| BAG-SAVE-07 | 메모 본문: 이 가방이 열려 있을 때만 `bags/{id}/notes` 구독해 메모에 채움. 저장할 때 본문을 떼고 바뀐 본문만 notes에 씀. 오프라인 모드 · 만들기 대기 가방은 본문이 가방 안에 그대로 |
| BAG-SAVE-08 | notes 구독 실패(권한 등)면 가방 안 본문만으로 열고 지우기는 안 함 |
| BAG-SAVE-09 | 메모 본문은 그 메모의 notes가 바뀐 경우에만 교체(목록 소식이 먼저 와서 방금 쓴 글을 되돌리지 않게) |
| BAG-SAVE-10 | 서버가 이미 반영한 변경(팩 옮기기 · 멤버 내보내기 · 넘기기 · 코드 재발급)은 화면에만 적용하고 다시 저장하지 않음(`applyServerChange`) |
| BAG-SAVE-11 | 되돌리기 스택(undo/redo) 없음. 삭제 · 다시 싸기만 토스트 되돌리기 |

| ID | 규칙 |
|---|---|
| BAG-NAV-01 | 화면 어디서나 오른쪽으로 밀면 뒤로(입력칸에서는 왼쪽 끝에서만 - shell.md). 메모 편집기가 열려 있거나 여러 개 선택 중이면 꺼짐 |

| BAG-KEEP-01 | 화면 켜두기: 브라우저 Wake Lock. 이 기기에 기억, 켜 두면 가방 화면이 열려 있는 동안만. 앱이 돌아오면 다시 요청. 지원 안 하면 켤 때 "이 기기에서는 화면 켜두기를 쓸 수 없어요". 켜면 "가방을 보는 동안 화면이 꺼지지 않아요" |
| BAG-GUIDE-01 | 사용 가이드 자동: 이 기기에서 처음 가방을 열 때 0.7초 뒤 한 번. 새 가방 · 읽기 전용 · 검색으로 들어옴 · 잠금 문이면 건너뜀. 닫으면 본 것으로 기록(localStorage, 못 쓰면 본 것으로 침) |
| BAG-GUIDE-02 | 단계 6개: 아이템 넣기(입력창) → 체크하고 고치기(첫 체크 팩, 누르기 동그라미) → 한 화면에 더 많이(1열/2열) → 다시 싸기 → 함께 챙기기 → 더보기. 화면에 없는 대상은 건너뜀(`lib/v2/guide.ts`) |
| BAG-RO-01 | 읽기 전용(무료 한도 초과로 잠긴 가방): 체크 · 추가 · 수정 · 삭제 · 날짜 · 설명 · 첨부 · 멤버 관리 등 모든 쓰기가 이용권 안내로 바뀜(guard). 이름 칸 · 입력창 · 다시 싸기 비활성, 아이템 · 팩 길게 누르기 → 이용권 안내. 보기 · 사진 보기 · 메모 열기(편집기 읽기 전용)는 됨 |
