# 팩 탭 (팩 보관함) — packs.md

기준 코드: v1.6.1 (2026-10-17 수정). 메모(editor) 팩을 열면 메모 편집기라 `memo.md`, 공유 받은 쪽(`/p` 화면 · 가져오기)은 `share.md`, 무료 10개 초과 잠금 판정은 `premium.md`, 탭바 · 넓은 화면 · 단축키는 `shell.md`에서 다룬다.

- 목록 화면: `components/v2/packs/PacksScreenV2.tsx`
- 계산(순수 함수): `components/v2/packs/packsModel.ts` (`entriesIn` · `pathTo` · `metaOf` · `pathLabel` · `moveTargets`), `lib/listSort.ts` `arrangeList`
- 체크리스트 팩 화면: `components/v2/packs/PackEditorV2.tsx`
- 시트: `packs/sheets/AddSheet.tsx` · `EntrySheet.tsx` · `MoveSheet.tsx` · `NameSheet.tsx` · `PackEditorSheets.tsx`(LibraryItemSheet · MoveDestSheet · AlsoAddSheet), `components/v2/sheets/PackShareSheet.tsx` · `QuickAddSheet.tsx`, `components/v2/ui/ReorderSheet`

## 5. PACK-ORD 순서

| ID | 규칙 |
|---|---|
| PACK-ORD-01 | 정렬(10/14 추가, 가방 홈과 같은 4가지): **최근순**(기본, 최근에 고친 순 = `updatedAt`, 없으면 만든 시각) / **이름순 (ㄱ→ㅎ)** / **이름 역순 (ㅎ→ㄱ)** / **직접 정한 순서**. 계정에 저장(`packSortBy`, 최근순은 "updatedAt"). 예전 기본값 "createdAt" 등 나머지 값은 최근순으로 읽음(`packsModel.packSortOf`). 모든 폴더가 같은 정렬을 씀 |
| PACK-ORD-05 | 정렬 시트: 목록 머리 줄 오른쪽 버튼(계정 모드 + 항목 2개 이상) → 제목 "정렬", 4가지 중 지금 것에 ✓ · 굵게. 고르면 닫힘(같은 것이면 저장 안 함, 실패 "정렬을 저장하지 못했어요"). 안내 "최근순은 최근에 고친 순서예요. 폴더는 항상 팩보다 위에, 고정한 항목은 항상 맨 위에 있어요. 폴더마다 같은 정렬을 써요." + 고정 아닌 항목이 2개 이상이면 "순서 바꾸기"(폴더 안 "'폴더' 순서 바꾸기") → PACK-ORD-03 |
| PACK-ORD-02 | 직접 정한 순서는 **폴더마다 따로**(`packOrderByParent[폴더 id \| "root"]`). 순서에 없는 항목(새로 만든 것)은 뒤에 만든 순으로 |
| PACK-ORD-03 | 순서 시트: 제목 "팩 순서" / 폴더 안 "'폴더' 순서". 두 묶음 "폴더" · "팩 · 메모"(서로 섞을 수 없음). 안내 "오른쪽 ≡를 끌어서 옮겨요. 폴더는 항상 팩보다 위에 있어요." + 고정이 있으면 " 고정한 항목은 항상 맨 위라 여기서 빠져요." 완료 = 폴더 순서 + 팩 순서를 한 번에 저장(쓰기 1번) + 정렬 "custom". 실패 "순서를 저장하지 못했어요" |
| PACK-ORD-04 | 고정한 항목은 묶음(폴더/팩) 안에서 맨 위, 고정한 순서대로 |
