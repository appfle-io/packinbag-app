## 대전제
- 로직(lib/*Service, firestore.rules, AuthProvider, TipTap 편집기)은 유지, 화면 컴포넌트만 교체
- 10/8부터 가방 안 메모 본문은 가방 문서가 아니라 `bags/{bagId}/notes/{packId}`에 저장한다(목록에는 제목·미리보기·검색용 앞 2,000자만). 화면은 그대로이고, 열린 가방만 본문을 따로 받아 온다
- BagEditorScreen(3,622줄) 등 거대 화면은 먼저 로직을 훅으로 분리 후 새 UI가 동일 훅 사용
- 제거 기능은 UI만 숨기고 Firestore 필드·데이터는 보존. 예외: 엑셀 가져오기·템플릿 공유 심사는 소스까지 제거
- 10/5 구 UI 화면 소스는 모두 삭제(필드·데이터는 그대로). 칸반 가방·댓글·리액션·시작 화면 설정·오늘 마감 팝업도 코드에서 빠짐

## 디자인 기준 (미니멀)
- 폰트: 기본 Pretendard. 사용자가 설정 > 화면 > 글꼴에서 지마켓 산스·개구·D2코딩으로 바꿀 수 있음(앱 전체·메모팩 본문 포함, 크기·줄 높이는 Pretendard에 맞춰 보정). 메모 속 코드는 항상 D2코딩
- 글자 크기 6단계 12/13/15/17/22/28
- 간격 4pt 단위(4/8/12/16/20/32/40), 모서리 6/8/14/full, 그림자는 바텀시트 · 떠 있는 탭바 2종(10/4)
- 색: 무채색 + 포인트 1개(딥그린 #2E5E4E)
- 앱 아이콘(10/6): 딥그린 배경 + 흰 백팩 + 옅은 초록 팩 두 톤. v1 주황 아이콘의 모양(팩이 든 백팩)은 그대로, 색만 바꿈. 로고(backpack-logo)·스플래시·favicon·포터블 아이콘도 같은 이미지
- 모션: 체크 160ms+햅틱, 접기 200~240ms, 화면 push/pop 280ms spring, 바텀시트 spring
- 임의값(text-[12.5px] 등) lint로 금지
- 화면 위에 뜨는 층(시트·가이드)은 뒤 화면이 어둡게 비쳐야 한다(scrim). 루트에 `.pib-v2-overlay`
- 포커스 테두리(브랜드색 2px)는 버튼 등 키보드 포커스에만. 글을 쓰는 칸(입력칸·메모 본문)에는 없음
- 사진·PDF 크게 보기는 화면 모드와 상관없이 늘 어두운 바탕, 위 줄 44px 동그란 버튼(사진 10/3, PDF 10/4 PdfViewer)
- 화면 위·아래 한 줄 안내(연결 상태 · 이메일 인증 · 홈 화면에 추가)는 하나의 모양: 높이 44px, 아이콘 16px + 한 줄 글 + 글자 버튼 + 닫기(10/4). 연결 끊김은 fill, 로그인 안내는 brand-soft
- 브라우저 기본 alert·confirm·prompt는 쓰지 않는다(10/4 점검 완료, 게스트 보기도 화면 안내로)
- 기다리는 화면(만드는 중·정리 중)은 하나의 모양: 화면이 바뀌는 중이면 바탕을 덮고 가운데 동그라미+문구, 여러 개 처리 중이면 뒤를 어둡게 비치고 카드에 진행 막대(10/3)

## 화면 틀 · 반응형 (10/3 셸 통합으로 확정)
| 폭 | 구성 |
|---|---|
| 900px 미만(폰·아이패드 세로) | 탭 화면 1단 + 떠 있는 하단 탭바. 가방·메모는 오른쪽에서 겹쳐 들어옴, 팩 편집은 바텀시트 |
| 900px 이상 | [목록 \| 상세] 2단. 목록 칸 아래 떠 있는 탭바 |
| 1200px 이상(PC·포터블) | [레일 \| 목록 \| 상세] 3단. 레일: 팩·가방·설정, 아래 빠른팩(+ 오프라인 표시) |
- 상세 칸에는 하나만: 팩·메모가 열려 있으면 그것, 아니면 가방. 가방 위에 팩을 열고 닫으면 가방으로 돌아온다. 비었으면 "새 가방 / 새 팩" + 단축키 안내
- 설정 하위 화면(프로필·휴지통 등)도 상세 칸에 열린다(10/5). 목록에서는 상세 칸에 열린 가방·팩 줄을 둥근 회색 바탕으로 강조
- 새 가방은 만드는 순간 저장되고, 손대지 않고 나가도 지우지 않는다(10/16, 예전에는 다른 가방을 고르거나 뒤로 가면 지웠다)
- 시트는 1024px 이상에서 화면 가운데 창(바깥·Esc·X로 닫기, 끌어내리기 없음). 그 아래는 바텀시트
- 단축키(맥 ⌘ / 윈도우 Ctrl): N 새로 만들기 · K 검색 · I 설정 · P 빠른팩 입력 · Esc 상세 닫기
  - 웹 브라우저 탭에서 ⌘N/Ctrl+N은 브라우저가 막는다(포터블은 됨)
  - 메모 본문 안에서 ⌘I는 기울임 우선
  - 툴팁에 OS별 표기("⌘K" / "Ctrl+K")
  - ⌘F(페이지 찾기)는 건드리지 않는다. 빠른팩은 ⌘P(인쇄 대신)
- PC 마우스 끌기 탭 전환은 없음(터치 전용). 길게 누르기 = 오른쪽 클릭
- 탭·목록 화면은 components/v2/ui/Screen.tsx만 쓴다(ScreenHeader px-5 pt-2 pb-3 / ScreenBody max-w-2xl px-5 pt-2 pb-8, 헤더 아이콘 44px·22px). 설정 하위 화면은 SubScreen(같은 헤더 + 왼쪽 뒤로)
- 한 단계씩 들어가는 화면은 PageStack으로 겹쳐 쌓는다

## 연결 흐름 (10/4 확정)
핵심: 인터넷이 되든 안 되든(폐쇄망 포함) 사용자는 같은 앱·같은 데이터를 끊김 없이 이어서 쓴다.
- 원칙 1. 로그인 세션이 있으면 언제나 계정 모드. 끊기면 Firestore 캐시로 계속 쓰고, 연결되면 알아서 동기화. 오프라인 모드로 빠지지 않는다
- 원칙 2. 세션이 없을 때만 오프라인 모드(이 기기 저장). 나중에 로그인하면 계정에 합친다
- 원칙 3. 인터넷이 꼭 필요한 기능만 막고, 누르기 전에(열기 전에) 이유를 알린다
- 연결 판단은 앱 전체가 하나(lib/v2/connectivity): 포터블 IPC · 웹 HEAD 요청. 끊김 5초 · 연결 30초마다 다시 확인(폐쇄망 복구도 감지)
- 시작: 세션 있음 → 계정 / 세션 없음 + 온라인 → 로그인 화면 / 세션 없음 + 끊김·폐쇄망 → 모든 플랫폼에서 바로 오프라인 모드
- 로그인 화면: 확인 중에는 로고만, 끊기면 "인터넷에 연결되지 않았어요"(오프라인 모드로 시작 / 연결 다시 확인), 연결되면 저절로 폼으로
- 상태 줄: 계정 모드 끊김 "연결이 끊겨 저장해 둔 내용을 보고 있어요 · 바뀐 내용은 연결되면 올라가요" → 복구되면 사라지고 "다시 연결됐어요" 토스트. 오프라인 모드 + 연결됨 "인터넷에 연결됐어요 · 로그인"(오프라인 모드 + 끊김에는 아무것도 안 띄움)
- 끊겨 있을 때 새 가방·팩: "만들기 대기"로 바로 만들고 목록·편집 그대로. 목록·캐러셀·팩 탭 줄에 "올리기 대기" 배지(10/5). 연결되면 자동으로 서버에 생성(같은 id), 배지는 사라짐. 무료 개수 초과면 남겨 두고 프리미엄 안내
- 끊겨 있으면 막는 것: AI(가져오기·빠진 것 확인·날씨·메모로 가방 만들기), 사진·파일 첨부(오프라인 모드는 허용), 가방 참여·공유 링크, 계정 연동·이용권·내 URL·공지·문의, 비밀번호 변경·탈퇴(흐리게)
- 오프라인 모드 → 로그인: 새로고침 없이 그 자리에서 전환, 로그인 뒤 "이 기기의 가방·팩 옮기기" 시트를 한 번 자동으로("오프라인으로 쓰던 가방 N개 · 팩 M개를 계정으로 옮길게요" / 나중에 하기). 무료 개수를 넘으면 거기서 멈추고 "N개를 옮겼어요. M개는 이 기기에 남겨 두었어요" + 프리미엄 안내(다시 해도 중복 없음)
- Firestore가 절전 복귀 등으로 멈추면(SDK 내부 오류) 화면을 덮고 "다시 연결하고 있어요" → 자동 새로고침. 2분 안에 또 멈추면 "연결을 다시 맞추지 못했어요 · 새로고침" 버튼만(10/6)
- 한계: iOS 앱은 server.url 구조라 폐쇄망에서 처음 실행은 안 됨(쓰던 중 끊김은 위 흐름대로)

## iOS 네이티브 (10/10~10/12 확정, iOS 1.5 · 1.6)
웹 화면은 server.url이라 웹 쪽 기능은 플러그인이 있을 때만(스토어의 예전 앱 보호). 상세는 저장소 `docs/packinbag_ios_native_plan.md`
- **알림**: 서버 푸시 3종(함께 쓰는 가방 활동 10분 묶음 · 나에게 맡긴 아이템 바로 · 새 멤버는 그룹장에게) + 로컬 알림(D-Day · 요일 반복). 광고성 알림 없음, 기본 켜짐(iOS 허용 창이 옵트인). 공유 가방을 처음 열 때 허용 창 1회
  - 설정 > 알림: 권한 상태 · 종류별 토글 · 테스트 알림
  - 가방 더보기 > 알림: "함께 쓰는 사람 소식"(이 가방 소식 받기 → 켜면 종류별, 새 멤버는 그룹장만, 설정에서 끈 종류는 흐리게) · D-Day 알림 · 반복 알림
  - 더보기 "알림" 줄 오른쪽 글: "소식"/"소식 일부" + D-Day · 반복 요약, 모두 꺼야 "꺼짐"
- **홈 위젯**(작게 · 중간 · 크게, iOS 17): 체크 아이템만, 누르면 바로 체크 · 챙긴 것 아래로. 위젯 편집 = 가방(곧 출발 · 고정 · 최근 + 검색, 보관함 가방 제외) → 팩(맨 위 가방 전체, 비우면 가방 전체) · 배경 · 글꼴 · 글자 크기 · 열 수(1.6). 아래 줄 "14시 05분에 새로고침" + ↻. 체크 아이템 없는 팩은 "체크할 아이템이 없어요"
  - 열 수(1.6): 중간 · 크게 1열/2열(기본 2열), 작게는 1열. 다 못 보여 줘도 "외 N개" 줄은 없다(그 자리에 아이템 한 줄 더, 남은 양은 제목 줄 n/m)
- **잠금화면 위젯**: 원형(남은 개수) · 한 줄 · 사각
- **잠금화면 실시간 현황**: 가방 더보기 > 잠금화면에 띄우기 → 팩(맨 앞 "전체") · 배경(시스템 · 라이트 · 다크 · 직접: 색 8개 + iOS 색 고르기 창 + 불투명도 0~100%) · 글자색(자동 · 흰색 · 검정 · 직접, 1.6부터 반영) · 글꼴 · 글자 크기. 시트에 잠금화면 미리 보기(10/12). 카드는 160pt 안(아이템 2열 2줄 + "외 N개 · 시각"). 다 챙기면 5분 뒤 내림(그 사이 해제 가능). iOS 8시간 제한 → 단축어 "잠금화면 다시 띄우기"를 자동화로. 다이내믹 아일랜드는 항상 다크
- **단축어 · Siri**: 빠른팩에 입력 · 가방에 추가(가방 → 팩, 비우면 미분류) · 팩인백 새로고침 · 잠금화면 다시 띄우기
- 알림 · 위젯 · 잠금화면을 누르면 그 가방이 열림
- **Siri · Spotlight 검색**(1.6, iOS 18+): 가방 · 가방 속 팩(부제 가방 이름) · 보관함 팩(부제 "보관함 · 아이템 N개" / "보관함 · 메모"). 누르면 가방 / 그 팩으로 스크롤 / 팩 탭에서 보관함 팩. 잠근 것은 안 나옴, 로그아웃하면 사라짐. 단축어 앱에도 "가방 열기 · 가방 속 팩 열기 · 보관함 팩 열기"
- **링크**(10/12): 유니버설 링크(1.6) - 초대 링크 · 공유 보기(`/v/…`)를 메시지 · 메모 · 사파리에서 누르면 바로 앱. 카톡 등 앱 안 브라우저는 브리지(아이폰 = 앱 열기, 없으면 앱스토어 / 안드로이드 = 기본 브라우저). 짧은 URL은 다른 사이트로 가는 링크가 있어 앱으로 돌리지 않는다

## 개인 잠금 (10/12 확정)
- 가방 · 가방 속 팩 · 보관함 팩을 **나만** PIN(4 또는 6자리, 기본 6) + Face ID(iOS 1.6)로. 함께 쓰는 멤버에게는 영향 없음
- 설정 > 잠금: PIN 만들기 · 바꾸기 · Face ID · 지금 잠그기 · 잠금 끄기(잠근 개수 표시). 무엇을 잠글지는 가방 더보기 · 팩 길게 누르기 · 팩 탭 길게 누르기
- 한 번 풀면 앱을 떠날 때까지 모두 풀림, 다른 앱 · 홈 화면 · 탭 전환이면 바로 다시 잠김
- 보관함에서 잠근 팩을 불러온 가방 팩도 같이 잠김(가방에서는 못 풀고 보관함에서 푼다)
- 잠근 것은 위젯 · 잠금화면 · 검색에 나오지 않는다
- 화면을 가리는 잠금이지 암호화가 아니다(휴대폰을 잠깐 빌려줄 때용). 무료 한도 초과 잠김은 화면에서 "읽기 전용"이라 불러 구분한다

## 화면 이동·제스처 (10/3 확정, 앱의 손맛 기준)
- 모든 가로 이동은 손가락을 실시간으로 따라온다. 30% 이상 끌었거나 빠르게 튕기면 그 속도대로 마저 가고, 아니면 제자리
- 탭(팩·가방·설정): 좌우로 밀면 탭 트랙이 따라옴. 첫·마지막 탭은 고무줄
- 탭 안 한 단계 들어가기(팩 폴더, 가방 → 보관함): 오른쪽에서 밀려 들어오고 아래 화면은 30% 물러남. 오른쪽으로 밀면 돌아감(스크롤 유지)
- 겹쳐 뜬 화면(가방, 메모 편집기, 설정 하위): 화면 어디서나 오른쪽으로 밀면 뒤로. 입력칸·메모 본문에서는 왼쪽 끝에서만
- 가로 스크롤 영역(칩·캐러셀·가방 목록)은 자기가 먼저 넘어가고, 끝에 닿으면 바깥 제스처로

## 확정된 결정
- **하단 탭바(10/4, 10/3 결정 변경)**: 떠 있는 분리형(독). [팩 · 가방 · 설정] 반투명 캡슐 + 오른쪽 빠른팩 검은 동그라미 +(탭이 아니라 버튼이라 뗌). 지금 탭은 캡슐 안 옅은 알약 + 진한 글자
  - 목록은 탭바 뒤로 지나가고, 마지막 줄은 탭바 위에서 끝난다. 여백은 탭바가 잰 실제 높이(--pib-dock)로 맞추고 숫자로 박지 않는다
  - 탭바 옆 빈 곳은 터치가 통과(스크롤 씹힘 없음), 탭바를 끌어도 탭이 넘어가지 않음
  - 터치 기기에서 탭 화면 입력칸에 글을 쓰는 동안 숨김. 토스트는 탭바 위로
  - 투명도 줄이기 설정이면 불투명
- **빠른팩 입력(10/3)**: 바텀시트. 체크/글 고르고 엔터로 연속 입력, 방금 넣은 것 목록, "빠른팩 열기 N개"
- **홈 구성**: 위에서부터 캐러셀 → 고정 → 가방 목록 → 보관함 한 줄
  - 캐러셀: 곧 출발(D-day 7일 이내) → 싸는 중(최근 체크 순), 고정 제외, 최대 5장, 5초 자동 넘김 + 멈춤, 동작 줄이기 존중
  - 고정: 최대 5개, 항상 위
  - 가방 목록: 고정만 빼고 전부, 5개씩 옆으로 넘김, 제목 줄에 개수
  - 정렬: 최근순 / 이름순 / 이름 역순 / 직접 정한 순서(폴더마다)
- **순서 바꾸기**: 목록 위 직접 드래그 대신 "순서 바꾸기" 시트(≡ 손잡이 + 완료). 폴더 칩·가방(폴더 안)·팩 탭(폴더 안, 폴더끼리/팩·메모끼리). 고정 항목은 빠짐
- 가방 상태: 비어 있음 / 싸는 중 / 다 쌌어요. 다시 싸기 기록은 날짜 한 줄(Bag.lastPackedAt)
- 출발일 표기: 화면에서는 "D-Day"(데이터는 Bag.travelDate)
- **아이템 넣기**: 하단 상시 입력창 하나. 기본 미분류, "넣을 곳" 칩으로 팩에 바로. 팩 머리 + · 필터 칩 연동, 대상은 바꿀 때까지 유지
- 다녀온 가방 → "보관함"(사용자별 archivedBagIds)
- **설정**: 화면(화면 모드·글자 크기·글꼴) + 가방(다 챙긴 아이템은 아래로). 글꼴은 시트에서 각 글꼴 미리보기를 보며 고름(10/4). 꾸밈 옵션은 삭제, 맞춤법 검사는 메모 편집기 안 토글
  - 하위(10/3): 프로필·버전·라이선스·휴지통·문의는 화면(SubScreen), 공지·FAQ·내가 만든 URL·오프라인 가져오기·계정 전환은 시트. 비밀번호 바꾸기·회원 탈퇴도 시트, 탈퇴는 닉네임 그대로 입력해야 버튼이 켜짐
- 공유: 멤버 시트, 접속자 아바타, 담당자 배지, 실시간 반영. 인원 안내는 만든 사람에게만, 가득 차면 프리미엄 안내
  - 10/7: 멤버 내보내기는 그룹장만, 일반 멤버는 나가기만. 가방 영구삭제는 그룹장(또는 혼자 남은 멤버)만. 접속자 표시는 3분 동안 입력이 없으면 사라짐. 탈퇴하는 그룹장의 공유 가방은 가장 먼저 들어온 멤버에게 넘어감
  - 보기 전용 링크(`/v`)에는 초대코드가 들어가지 않는다. `?code=`가 붙은 링크만 "참여하기"
- 메모팩: 가방 안 섹션 + 미리보기 3줄, 탭하면 전체 편집기. 툴바 1줄. 마크다운 붙여넣기(서식 HTML 우선)
  - 10/8: 가방을 열자마자 메모를 누르면 본문을 받을 때까지 "메모를 불러오고 있어요"(가운데 한 줄). 그동안 메모 휴지통·보관함 저장은 "메모를 불러오는 중이에요. 잠시 후 다시 해 주세요" 토스트
  - 홈 검색은 가방 메모의 앞 2,000자까지 찾는다(보관함 메모는 전체)
  - 메모 편집기를 닫을 때 본문에서 지운 사진·파일을 Storage에서도 지운다(다른 곳이 쓰거나 공유 가방이면 남김)
- 파일: 가방 사진은 있을 때만 썸네일 줄(누르면 사진 크게 보기), 메모팩 첨부는 툴바
- URL: 바텀시트 하나로 통합(서버 API 유지)
- 폴더: 가방 폴더 1단계(홈 칩, 이름 겹침 방지, 순서 지정), 팩 폴더 중첩 유지(드릴다운 + 경로)
- 아이템 부가 기능은 길게 누르기 시트 하나로. 여러 개 선택은 입력창 자리에 "N개 선택 · 취소 · 삭제 · 옮기기"

- **시작 공지(10/3)**: 앱을 열 때 안 본 공지를 바텀시트로 하나씩. "다시 보지 않기"(영구) / "확인·다음 공지"(이번만). 가이드·앱 설치 슬라이드는 v2에서 띄우지 않음
- **알림(10/3)**: 종에 점만(안 읽은 알림 빨강). 시트에 알림 목록 + 모두 읽음. 새 버전 안내(초록 점 · 새 버전 줄)는 10/19에 빼고 설정 > 버전 정보에서만 확인(열 때 한 번, "업데이트"는 앱 버전이 낡으면 App Store · 아니면 다시 불러오기, 사용자에게는 구분 없이)
- **로그인(10/3)**: 로그인/가입하기 전환 한 화면. 가입하면 닉네임·캐릭터를 같은 화면에서. 비밀번호 재설정·가입 완료는 시트. 인터넷이 없으면 오프라인 시작 화면 먼저
  - 10/4: 포터블은 이메일·게스트만(Google·Apple 숨김 - 앱 안 팝업이 기본 브라우저로 빠지고 127.0.0.1은 승인 도메인이 아니며 구글이 임베디드 브라우저를 막음). 오류 문구는 네트워크·팝업 막힘·계정 불일치까지 한국어로
