| 전송 중 암호화 | **예**(HTTPS · Firebase) |
| 계정 생성 방법 | 사용자 이름 · 비밀번호(이메일), OAuth(Google), 기타(게스트 — 익명 계정) |
| 계정 삭제 요청 방법 | 앱: 설정 > 프로필 > 회원 탈퇴 / 웹 URL: **https://packinbag.seeuson.com/delete-account** (10/22) |

- "공유(Share)"는 **없음**으로 답한다: Gemini(AI) · Google 지오코딩 · Nominatim · Open-Meteo · Resend · Vercel은 우리 대신 처리하는 서비스 제공업체라 Play 정의상 공유가 아님. 멤버끼리 가방을 보는 것은 사용자가 직접 한 공유라 해당 없음

### 수집하는 데이터 (모두 "공유 안 함 · 일시 처리 아님")

| Play 데이터 유형 | 수집 | 필수/선택 | 목적 | 근거 |

- 앱 정보 및 성능(비정상 종료 로그 · 진단): 분석 · 크래시 SDK 없음(package.json에 Firebase Analytics · Crashlytics · Sentry 없음)
- 기기 또는 기타 ID: A단계에는 없음
